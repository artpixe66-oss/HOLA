# Wallet Fidélité

App de cartes fidélité digitales pour commerçants.

## Installation

```bash
npm install
```

Crée un fichier `.env.local` à la racine :

```
NEXT_PUBLIC_SUPABASE_URL=https://dyfeldbimtnuhffovvoi.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_FN2nSd29vuS0fbLHcTdSyg_Xv74HyGk
```

## Base de données

Dans Supabase > SQL Editor, exécute le contenu de `supabase/schema.sql`.

## Lancer

```bash
npm run dev
```

Ouvre http://localhost:3000
